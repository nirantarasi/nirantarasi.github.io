Nirantara team

Nirantara builds cloud-native platforms, Kubernetes operators, and AI infrastructure in the open. The projects are maintained by Vinaykumar V A, with contributions from the community.

The projects

The team maintains four projects, all developed in the open on GitHub:

  • k3sctl: declarative K3s cluster lifecycle over SSH. Apache-2.0.
  • mssql-mcp-go: read-only MCP server for Microsoft SQL Server. MIT.
  • postgres-mcp-go: read-only MCP server for PostgreSQL. MIT.
  • omniroute-operator: Kubernetes operator for OmniRoute. Apache-2.0.

Contributors

Nirantara's projects accept contributions from anyone. Bug reports, documentation fixes, and pull requests are reviewed on the repository where the change belongs. The organisation page is at github.com/nirantarasi.

If you contribute regularly and would like to be listed on this page, open an issue in the relevant repository with your GitHub handle and the work you do.

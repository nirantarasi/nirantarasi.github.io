OmniRoute CR ​

An OmniRoute resource describes one OmniRoute deployment. The operator reconciles a Deployment, Service, PVC, and optional Ingress from it.

yaml
apiVersion: gateway.omniroute.ai/v1alpha1
kind: OmniRoute
metadata:
  name: omniroute
  namespace: ai-platform
spec:
  image:
    repository: diegosouzapw/omniroute
    tag: "3.8.51"
  replicas: 1
  service:
    type: ClusterIP
    port: 20128
  credentials:
    existingSecret: omniroute-secrets
  config:
    existingConfigMap: omniroute-config
  persistence:
    enabled: true
    size: 1Gi

Core ​

FieldTypeDefaultDescription
spec.image.repositorystringdiegosouzapw/omnirouteOmniRoute container image
spec.image.tagstring3.8.51Image tag
spec.image.pullPolicystringIfNotPresentImage pull policy
spec.replicasint1Pod count (max 1 — SQLite is single-writer)
spec.resourcesResourceRequirements—CPU and memory requests and limits
spec.env[]EnvVar—Additional environment variables

Service ​

FieldTypeDefaultDescription
spec.service.typestringClusterIPClusterIP, NodePort, or LoadBalancer
spec.service.portint20128Service port
spec.service.annotationsmap[string]string—Service annotations, for example for an AWS NLB

Configuration and credentials ​

FieldTypeDefaultDescription
spec.config.existingConfigMapstring—ConfigMap with OmniRoute environment variables (injected with envFrom)
spec.credentials.existingSecretstring—Secret with JWT_SECRET, API_KEY_SECRET, and INITIAL_PASSWORD

Persistence ​

FieldTypeDefaultDescription
spec.persistence.enabledbooltrueCreate a PVC for the data directory
spec.persistence.sizestring1GiPVC storage size
spec.persistence.storageClassstringcluster defaultStorageClass name
spec.persistence.accessModestringReadWriteOncePVC access mode

Health probes ​

FieldTypeDefaultDescription
spec.probes.livenessPathstring/api/monitoring/healthHTTP path for the liveness probe
spec.probes.readinessPathstring/api/monitoring/healthHTTP path for the readiness probe
spec.probes.startupPathstring/api/monitoring/healthHTTP path for the startup probe

The operator fills in sensible timing defaults for all three probes.

Ingress ​

FieldTypeDefaultDescription
spec.ingress.enabledboolfalseCreate an Ingress resource
spec.ingress.classNamestring—IngressClass name, such as nginx
spec.ingress.hoststring—Hostname for the Ingress rule
spec.ingress.tls.secretNamestring—TLS Secret name
spec.ingress.annotationsmap[string]string—Ingress annotations

Redis (rate limiting) ​

FieldTypeDefaultDescription
spec.redis.urlstring—Redis connection URL, such as redis://redis:6379
spec.redis.existingSecretstring—Secret containing a REDIS_URL key
spec.redis.keyPrefixstring—Redis key namespace prefix

Encryption (database at rest) ​

FieldTypeDefaultDescription
spec.encryption.existingSecretstring—Secret containing STORAGE_ENCRYPTION_KEY
spec.encryption.keyVersionstring—Encryption key version, for key rotation

Reverse proxy ​

FieldTypeDefaultDescription
spec.basePathstring—Sets OMNIROUTE_BASE_PATH, for example /omniroute

Auto-derived environment variables ​

The operator sets these from the resource, so you do not repeat them in spec.env:

VariableSourceDescription
NODE_OPTIONSspec.resources.limits.memory--max-old-space-size=<75% of the memory limit in MB> to prevent Node.js OOM kills
OMNIROUTE_BASE_PATHspec.basePathReverse-proxy base path
REDIS_URLspec.redis.url or the referenced SecretRedis connection URL
REDIS_KEY_PREFIXspec.redis.keyPrefixRedis key namespace prefix
STORAGE_ENCRYPTION_KEYspec.encryption.existingSecretDatabase encryption key
STORAGE_ENCRYPTION_KEY_VERSIONspec.encryption.keyVersionEncryption key version

Status ​

FieldDescription
status.conditionsStandard conditions describing reconciliation
status.readyReplicasNumber of ready OmniRoute replicas
status.observedGenerationGeneration last processed by the operator
status.phaseHigh-level phase of the deployment

Check it with:

sh
kubectl get omniroute omniroute -n ai-platform -o yaml

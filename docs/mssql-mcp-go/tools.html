Tools ​

Every tool below issues read-only catalog queries or validated SELECT / WITH statements. Mutating SQL is rejected before execution.

Core query ​

ToolDescription
execute_queryRun a read-only SELECT / WITH query
health_checkCheck connectivity and connection-pool stats
